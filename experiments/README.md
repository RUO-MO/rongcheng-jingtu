# Experiment Reproduction Guide (`experiments/`)

This directory contains the scripts, raw data and result artefacts for all experiments in Chapter 4 of the paper. **With the same Python environment and dependencies, every reported number can be reproduced bit-for-bit using the fixed random seeds.**

## Directory Structure

```
experiments/
├── scripts/                        # all runnable scripts
│   ├── run_sci_benchmark.py        # main experiment: Tables 1-7 + sensitivity data
│   ├── run_extra_algos.py          # extended algorithm comparison (Greedy/GA/SCDP)
│   ├── gen_path_detail.py          # optimal path details for each instance size
│   ├── generate_paper_tables.py    # English LaTeX tables + Figure 4
│   ├── generate_paper_tables_zh.py # Chinese tables
│   ├── generate_path_table.py      # concise path table printed to the terminal
│   ├── plot_sensitivity.py         # Figure 4 (English version)
│   ├── plot_sensitivity_zh.py      # Figure 4 (Chinese version)
│   └── verify_results.py           # result consistency checks
├── data/                           # raw experiment data (committed to the repository)
├── results/                        # tables and logs generated by the scripts
├── docs/                           # experiment reports and discussion
└── requirements.txt
```

## Environment

- Python 3.9, `pip install -r experiments/requirements.txt` (numpy / scipy / matplotlib)
- Reference environment: Windows 10, Intel Core i7-13700K, 16 GB RAM (see `data/hw_env.txt`)
- All scripts can be run from the repository root; output paths are resolved by constants inside each script, so there is no need to `cd` into a subdirectory.

## Random Seeds and Hyper-parameters

| Item | Value |
| --- | --- |
| Global seeds | `random.seed(42)`, `np.random.seed(42)` |
| Per-instance seeds `SEED_MAP` | 5 → 47, 8 → 361, 10 → 52, 12 → 54, 15 → 57 |
| Independent repetitions | `N_REPS = 30` (30 runs each for GA/Greedy; SCDP is deterministic and runs once) |
| GA | population 200, 500 generations, crossover 0.8, mutation 0.1 |
| Normalisation | Min-Max; the distance matrix excludes the diagonal |
| Significance | Wilcoxon signed-rank test, `p < 0.05` |

> If seeds or parameters are changed, the existing results in `data/` will no longer match. Do not overwrite the original data; back it up before running.

## Reproduction Commands

```bash
# 0) Dependencies
pip install -r experiments/requirements.txt

# 1) Main experiment (Tables 1-7; slowest, since GA requires many repetitions)
python experiments/scripts/run_sci_benchmark.py

# 2) Extended algorithm comparison
python experiments/scripts/run_extra_algos.py

# 3) Path details
python experiments/scripts/gen_path_detail.py

# 4) Tables and figures
python experiments/scripts/generate_paper_tables.py
python experiments/scripts/generate_paper_tables_zh.py
python experiments/scripts/plot_sensitivity.py
python experiments/scripts/plot_sensitivity_zh.py

# 5) Verification
python experiments/scripts/verify_results.py
```

## Data Dictionary

### `data/raw_results.json`

| Top-level key | Contents |
| --- | --- |
| `hardware` | Experiment platform information (CPU, memory, Python version) |
| `table1_2` | Distance / AQI / composite cost / optimality gap / runtime for each instance size and algorithm |
| `table3` | Route comparison before and after AQI fusion |
| `table4` | Recommendations for the three preference modes |
| `table5` | System response time (data acquisition / algorithm / system overhead / P95) |
| `table6` | Functional test results |
| `table7` | Summary of overall results |

### `data/extra_algos_results.json`

Keys are instance sizes (`"5"`, `"8"`, `"10"`, `"12"`); values are arrays of per-run metrics for each algorithm.

### `data/path_details.json`

Keys are instance sizes (`"5"`–`"15"`); each record contains the optimal visiting order, per-edge costs and total cost, used for the appendix path table. `results/生成地名版本的路径表.docx` is the corresponding place-name version.

### `data/weight_sensitivity_data*.json`

| Key | Meaning |
| --- | --- |
| `alpha_values` / `beta_values` | Weight sweep values (β = 1 − α) |
| `distances` / `aqi_exposures` | Distance and pollution exposure of the corresponding routes |
| `comprehensive_costs` | Composite cost |
| `paths` | Path sequences additionally stored in the Chinese version |

### `results/`

| File | Produced by |
| --- | --- |
| `paper_tables.tex`, `table1_2.tex` | `run_sci_benchmark.py` / `generate_paper_tables.py` |
| `paper_tables_zh.md`, `paper_tables_zh.tex` | `generate_paper_tables_zh.py` |
| `Discussion.txt` | `generate_paper_tables.py` |
| `benchmark_output*.txt` | Console logs of the benchmark runs |
| `生成地名版本的路径表.docx` | Place-name mapping of the path details (appendix material) |

## Result Verification

`verify_results.py` rereads the JSON files under `data/` and checks the key metrics reported in the tables (for example, the SCDP composite cost 5.6647 and the Greedy optimality gap of 8.10% at n = 12). If values differ from the paper, first check whether the Python/NumPy versions or the seeds were changed.

## Notes

- The experiment instances consist of geographic coordinates and AQI data generated from fixed seeds and are therefore **synthetic instances**. The online system obtains AQI from the Open-Meteo real-time API; the two are not directly comparable in absolute terms.
- The API-call latency in Table 5 is simulated as `U(200, 800) ms` to represent AMap Web Service response times, while the DP runtimes come from the same batch of N = 30 repetitions.
